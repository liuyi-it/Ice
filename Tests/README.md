# 回归检查

在仓库根目录执行：

```sh
Tests/run-regressions.sh
```

脚本使用 Xcode 的 Swift 编译器，直接编译 `MouseState`、三个事件监视器、`TaskTimeout` 和 `AsyncSerialQueue` 的生产源码；不需要新增 Xcode target 或下载测试依赖。二进制和模块缓存写入已忽略的 `build/RegressionTests/`。检查失败返回非零退出码，单个检查进程运行超过 20 秒也会失败。

检查覆盖：

- 读取鼠标状态并运行事件跟踪循环后，已排队的左右键松开事件仍保持数量和顺序。
- 鼠标静止等待响应取消。
- 本地、通用事件发布者遵守 Combine 的需求量；在回调中取消后不再投递。
- 三种事件订阅取消后释放订阅者，即使外部仍持有 subscription。
- 有超时的操作正确返回结果、传播错误、在超时和父任务取消时结束子操作。

- 异步移动在等待事件、刷新缓存、保存布局期间保持串行；排队取消、执行中取消和失败均释放队列，25 个快速请求不会交叉执行。

检查需要 macOS 的当前图形登录会话。仅创建没有窗口的检查进程，并向自己的 AppKit 队列发送事件；不移动光标、不向其他应用注入输入、不修改用户设置。

`run-movement-checks.py` 从 `MenuBarItemManager` 提取实际的落点计算、事件手势和移动重试方法，在模拟的窗口位置及事件收发边界上编译执行；没有复制另一套移动实现。CoreGraphics 只创建事件对象，不向系统投递。它覆盖拖起后左右目标移位、目标消失后的松键清理、错误落点重试和重试耗尽。受限沙箱可能阻塞 CoreGraphics 初始化，此时需在正常图形会话运行。

## 缺陷复现依据

2026-09-28 的 Ice 0.11.12（1117）现场两次采样均落在菜单栏按钮跟踪循环中的 `RunLoopLocalEventMonitor`。原实现取出并重新投递事件，独立复现中一次鼠标松开事件在三轮循环内触发了三次 handler，弱引用集合没有阻止重复处理。

当前实现使用系统鼠标状态和空闲时间，移除了该 observer 及事件回灌。队列保留检查覆盖这一行为约束；它不能证明已安装应用的实际 CPU 改善。

同一套回归检查使用旧版三个事件订阅器时，会在本地和通用订阅的需求量检查、取消后释放订阅者检查中失败；修复版 10 项检查均通过。

2026-09-28 19:47:29 的布局页拖拽日志显示两个移动相隔 4 毫秒启动，随后同时发生 `EventTap 2` 超时。旧实现仅用计数器表示“正在移动”，不能阻止 MainActor 上的异步重入。现在移动、点击及缓存更新共用串行队列，布局拖拽的移动、位置确认、刷新缓存和保存作为一个完整操作执行。

19:59 的第二次现场日志中，事件已投递并记录“Successfully moved”，随后到位检查超时。实际窗口 110 位于 Ice 图标右侧，而请求为左侧。旧实现用拖起前的目标坐标发送松键事件，并把任意位置变化当作成功；现改为拖起后读取目标位置，且每次尝试都确认最终到位后才返回。

## 手动更新版本的打包检查

Debug、Release 构建后及安装后分别运行：

```sh
python3 Tests/check-manual-updates.py /path/to/Ice.app
```

检查读取实际产物的 Info.plist、Mach-O 动态依赖和包内文件，确认没有 Sparkle 配置、链接或更新助手。它不启动应用，也不访问更新服务器。对移除更新前的旧安装包运行应失败。

设置窗口的“关于”页不应再显示自动检查、自动下载、检查更新按钮及上次检查时间；菜单栏右键菜单也不应显示“检查更新”。仍须人工确认页面布局和菜单交互。

## 安装后人工验证

以下场景需要使用按项目签名流程安装的修复版，在实际 macOS 会话中验证：

1. 连续点击、按住后松开 Ice 按钮，拖动菜单栏项目，关闭菜单；采样确认没有持续忙循环，并记录空闲 CPU。
2. 左右键同时按住、依次松开，确认仍有按键按住时不会自动隐藏或移动项目。
3. 在布局页快速连续拖动同一和不同图标，跨 visible、hidden、always-hidden 分区及区内调整顺序，确认无超时、最终位置正确；检查取消拖拽、拖动后的持久化和重启后恢复。
4. 多显示器、全屏 Space、刘海和系统自动隐藏菜单栏场景。
5. 快速切换应用、浅色和深色外观，确认菜单栏覆盖层位置正确；重复打开和关闭 Ice Bar、设置窗口后检查内存。
6. 快捷键注册、修改、冲突和重启恢复。
7. 辅助功能或屏幕录制权限未授予、授予和撤销后的行为。

构建、静态分析和这些独立回归检查不能替代以上人工场景。
